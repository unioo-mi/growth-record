# 小小足迹 · 孩子课外实践成长记录

一个基于 React + Vite 的本地优先 Web App，用来记录孩子在课外实践中的问题、知识、工具和长期项目。

## 已实现功能

- 问题库：问题内容、日期、触发场景、关联知识/工具
- 知识图谱库：德智体美劳五维分类、核心收获与跨模块关联
- 工具库：名称、掌握程度、首次学习时间、适用场景
- 项目库：起止时间、目标、关联记录、最终成果、项目复盘
- 任意两个不同模块的记录可以互相关联，并支持双向查看
- 图片、语音、短视频和普通文件录入
- 浏览器内直接录音；不支持时仍可上传音频文件
- IndexedDB 本地持久化，刷新不丢失
- 全局搜索、模块筛选、成长首页统计
- 整库导出与导入备份
- 桌面侧边栏与手机底部导航响应式布局

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可。

## 生产构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`。应用使用 HashRouter，部署到静态服务器时不需要额外配置路由回退。

## 数据说明

- 所有记录、关联和附件都保存在当前浏览器的 IndexedDB 中。
- 不会上传到服务器，也没有登录和云端同步。
- 清理浏览器数据、使用隐私模式或更换设备后，本地数据不会自动迁移。
- 建议在「设置与备份」中定期导出完整备份。
- 单个附件上限为 120 MB；大量视频会明显增加浏览器存储占用。
- 建议使用较新的 Chrome、Edge、Safari 或 Android 浏览器。

## 浏览器冒烟测试

项目内包含基于 Playwright Core 和本机 Edge 的冒烟测试脚本，覆盖四个模块创建、跨模块关联、附件、刷新持久化、搜索、移动端布局、备份导出与恢复。

先启动开发服务器：

```bash
npm run dev -- --host 127.0.0.1
```

然后在另一个终端执行：

```bash
node scripts/smoke.mjs
```

脚本默认使用 Windows 上的 Edge 路径。其他环境需要修改 `scripts/smoke.mjs` 中的 `executablePath`。
